# Concept

**Name:** Ship This Weekend

**One-sentence description:** A weekend-project idea generator for developers — click a button, get a slightly absurd, opinionated, buildable-in-48-hours side project pitch with a stack, a time estimate, and a "vibe."

**Target search keywords:**
- side project ideas
- weekend project ideas
- what should I build
- random project generator for developers

**Target sharing channels:**
- r/SideProject, r/webdev, r/programming
- Hacker News ("Show HN")
- Indie Hackers
- Developer Twitter/X (the output is screenshot-bait)

**Target audience:** Developers scrolling on a Friday night wondering what to build, indie hackers between projects, juniors looking for portfolio ideas.

**Why this concept:**
- **Passes the 4+ test:** one-sentence pitch ✅, has search demand AND shareability ✅, value in <10s (one click) ✅, 100% static (combinatorial JS, no backend) ✅, output is screenshot-shareable ✅.
- **Two growth vectors at once:** SEO (people Google "side project ideas") *and* virality (funny outputs spread on Twitter/Reddit).
- **Cheap to iterate:** more templates and more word pools = more variety, no infrastructure changes.
- **Each generated idea is permalinked** (`?seed=N`), so shared links land back on the site instead of dying as screenshots.

**Anti-pillars (what this is NOT):**
- Not a serious VC-grade idea generator.
- Not an AI/LLM wrapper.
- Not a directory of real projects.
- Not a quiz, todo app, or productivity tool.

**Success signal for the concept itself:** if generated ideas get shared on Twitter or Reddit at least once without prompting in the first 30 days, the concept is working. If not, pivot the *output style* (not the concept) — make it weirder, sharper, more opinionated.
