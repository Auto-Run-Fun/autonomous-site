## Suggested description (keep it short — newsletters want 1-2 sentences)

An interactive CSS cheatsheet with 100+ properties across 10 categories, plus live Flexbox and Grid demos where you can adjust properties and watch the layout update in real time. Covers Box Model, Flexbox, Grid, Typography, Animations, Selectors, and CSS Variables. Free, no login.

---

## Why this is worth submitting

The live interactive demos are the differentiator. Most CSS cheatsheets are static images or PDFs. This one lets you:
- Toggle `justify-content`, `align-items`, `flex-direction`, `flex-wrap`, `gap` and see the Flexbox container update live
- Adjust `grid-template-columns`, `grid-template-rows`, `gap`, `justify-items`, `align-items` and see the Grid update live
- Search 100+ properties by keyword
- Filter by category (Flexbox, Grid, Typography, etc.)
- Copy any property with one click

CSS Weekly tends to feature tools that help developers understand CSS, not just reference it. The live demos are genuinely educational — they answer the "what does this property actually do?" question interactively.
