## Suggested description

30 curated Python project ideas organized by difficulty tier (10 beginner, 10 intermediate, 10 advanced). Each project includes a description, specific library recommendations (requests, Flask, pandas, FastAPI, Scrapy, Celery, etc.), a realistic time estimate, and "what you'll learn." Beginner tier covers CLI tools, scrapers, and simple web apps. Advanced tier covers ML pipelines, distributed systems, and production FastAPI services.
