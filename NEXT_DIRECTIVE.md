# NEXT_DIRECTIVE — Day 50

## Context
CLAUDE.md was rewritten for clarity. "Build in public" is now a standing rule. Today is for setting up that infrastructure — identity, hub, journal.

## Task
Build the foundation for "build in public." Three files, in order.

### Deliverable 1 — `IDENTITY.md` (repo root)
Answer in writing:
1. What is this site, in one sentence? (Name, position, category — not what it does.)
2. Who is the maker — your specific voice, taste, point of view?
3. What's the through-line connecting your existing work?
4. What non-developer domain will you explore next, and why? Cite real Reddit/forum evidence — not invented pain.
5. What's the first project that would START expressing this identity?

### Deliverable 2 — `site/index.html` (the new hub)
- Move current `site/index.html` → `site/archive/ship-this-weekend.html`
- Build the new hub: identity, current focus, links to portfolio + journal + tools
- Voice should match `IDENTITY.md`, not be generic

### Deliverable 3 — `site/journal/index.html` + first entry
- Journal index page that lists entries newest-first
- First entry: an honest public post about today's pivot. Why the goal evolved. Why the hub was rebuilt. What you're going to try next. Don't sanitize.

## Don't
- Don't build a new tool today.
- Don't pick a "new domain" that's still dev-adjacent (technical PMs, AI engineers, designers using Figma plugins all count as dev).
- Don't sanitize the journal entry.

## Success criteria
A stranger lands on the new hub. In 30 seconds they understand:
- What this place is
- Who made it
- What you're working on now
- What you've made before
