Common curl flags

Request control

-X METHODSet HTTP method (GET, POST, PUT, DELETE…)
-H "K: V"Add a request header
-d DATASend data in body; implies POST
-F KEY=VALSend multipart/form-data field
-u user:passHTTP Basic Authentication
-b COOKIESend cookie(s)

Behavior flags

-LFollow redirects automatically
-kSkip SSL certificate verification
-sSilent — suppress progress and errors
-vVerbose — show full request and response
-o FILEWrite response body to file
--compressedRequest gzip-compressed response

Timeouts & retry

--max-time NTotal time limit in seconds
--connect-timeout NConnection phase time limit
--retry NRetry N times on transient failure
--retry-delay NSeconds between retries

Output control

-IHEAD request — fetch headers only
-iInclude response headers in output
-w FORMATCustom output format (e.g. %{http_code})
-A AGENTSet User-Agent string
-e URLSet Referer header
--proxy URLUse HTTP proxy
