CSS FAQ

What is CSS flexbox and when should I use it? +
CSS Flexbox (Flexible Box Layout) is a one-dimensional layout model for arranging items in a row or column. Use flexbox for navigation bars, centering elements, distributing space among items, and any layout along a single axis. For two-dimensional layouts (rows AND columns simultaneously), use CSS Grid instead.
What is the difference between CSS Grid and Flexbox? +
Flexbox works along one axis at a time (either row or column), making it ideal for components and small-scale layouts. CSS Grid works in two dimensions simultaneously (rows and columns), making it ideal for page layouts and complex grid-based designs. You can nest them — Grid for the overall layout, Flexbox for components within cells.
How do I center a div in CSS? +
The modern way: set the parent to display: flex; align-items: center; justify-content: center; — this centers the child both horizontally and vertically. For absolute centering: position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); For horizontal centering only: margin: 0 auto; with a defined width.
What are CSS custom properties (variables)? +
CSS custom properties let you store values to reuse throughout your stylesheet. Define with double dash prefix: --primary-color: #3b82f6; and use with var(): color: var(--primary-color); They cascade and inherit, making them ideal for themes and design systems. Unlike Sass variables, CSS variables work at runtime and can be changed with JavaScript.
How do CSS media queries work? +
Media queries apply CSS rules based on viewport conditions. The most common use is responsive breakpoints: @media (max-width: 768px) { /* mobile styles */ }. Modern approach uses min-width (mobile-first): start with mobile styles, then use @media (min-width: 768px) to add styles for larger screens. Common breakpoints: 640px (sm), 768px (md), 1024px (lg), 1280px (xl).
What does position relative vs absolute vs fixed mean in CSS? +
position: relative moves an element relative to its normal position, creates a positioning context for absolute children. position: absolute removes from normal flow, positions relative to the nearest non-static ancestor. position: fixed positions relative to the viewport and doesn't scroll. position: sticky acts like relative until it hits a scroll threshold, then acts like fixed.
How do CSS transitions and animations differ? +
CSS transitions animate property changes between two states, triggered by events (like :hover). They're defined on the element and fire when a property changes: transition: color 0.3s ease;. CSS animations (using @keyframes) play automatically or on load, can loop, and can have multiple steps. Use transitions for hover effects; use animations for loading spinners or sequences.
What is the CSS box model? +
Every element has: content, padding (space inside border), border, and margin (space outside border). By default (box-sizing: content-box), width applies to content only. Use box-sizing: border-box globally (* { box-sizing: border-box }) to make width include padding and border — much more intuitive for layout work.
