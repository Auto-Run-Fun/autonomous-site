Decode any cron schedule into plain English — field by field, plus the next 10 run times in your timezone.
Input
*/15 9-17 * * 1-5
Output
Every 15 minutes from 9:00 AM to 5:00 PM, Monday through Friday Minute: every 15 minutes Hour: 9 AM to 5 PM DOM: every day Month: every month DOW: Mon – Fri

Break any regular expression into its parts. No regex experience needed to understand the output.

Output
^ start of string [\w.-]+ one or more: word char, dot, or dash @ literal @ [\w.-]+ one or more: word char, dot, or dash \. literal dot \w{2,} two or more word characters $ end of string

SQL Explainer
Paste any SELECT query — inherited from a legacy codebase or generated by an ORM — and get a clause-by-clause breakdown.
Input
SELECT name, COUNT(*) AS orders FROM users JOIN orders ON users.id = orders.user_id WHERE users.active = 1 GROUP BY name ORDER BY orders DESC LIMIT 10
Output
Returns name, orders from users (joined with orders) — where active equals 1 — grouped by name — sorted by orders ↓ SELECT: name, orders FROM: users JOIN: orders on users.id = orders.user_id WHERE: active equals 1 GROUP BY: name ORDER BY: orders (descending) LIMIT: first 10 rows

Stack Trace Explainer
Paste a Python, JavaScript, or Java error. Get a plain-English breakdown: what the error type means and which line caused it.
Input

Output
Error: TypeError (Python) Crashed at: app.py, line 23 TypeError means you tried to use [] or . on something that is None (null). data["user"] returned None, so data["user"]["email"] failed.

curl & HTTP Header Decoder

Why these tools exist

Every developer inherits code they didn't write. A cron job set up three years ago. A regex nobody wants to touch. A SQL query from the ORM. A stack trace from a user report. A curl command from a Slack message.

The alternative — Google the syntax, open docs, piece it together — takes five minutes and costs focus. These tools take five seconds. Paste the thing. Read the English. Move on.

All five tools run entirely in your browser. Nothing is sent to a server. No account needed.

Common questions

How do I decode a cron expression?
Paste it into the Cron Expression Explainer. It shows each field in plain English and the next 10 times the job will fire.
How do I understand a regular expression without knowing regex?
Paste it into the Regex Explainer. Every token — anchors, character classes, quantifiers, groups, lookaheads — gets its own plain-English line.
How do I read a SQL query I didn't write?
Paste it into the SQL Explainer. You'll get a one-sentence summary plus a clause-by-clause breakdown — SELECT through LIMIT.
How do I decode a Python or JavaScript stack trace?
Paste the full error into the Stack Trace Explainer. It identifies the error type, the failing line, and the most likely causes for Python, JavaScript, and Java.
How do I understand what a curl command does?
Paste it into the curl & HTTP Header Decoder. Every flag gets explained, and you'll see the equivalent Python requests and JavaScript fetch code.
Do these tools send my data anywhere?
No. Every tool runs entirely in your browser. Paste your code, regex, query, or error — nothing leaves your machine.
