LLM System Prompt Templates

Production-ready starting points for the most common AI agent types.

Copy the prompt, replace the [BRACKETED] placeholders, and ship. Each template includes the structure that matters — tone rules, output format, escalation paths — the things you forget to add when writing from scratch.

12 templates
🎧
Support
Customer Support Agent
Resolves inbound support tickets, asks targeted clarifying questions, escalates when it can't solve the issue.
System Prompt
Customize these placeholders
  • [COMPANY NAME] — Your company or product name
  • [PRODUCT/SERVICE DESCRIPTION] — One sentence: what your product does and who uses it
  • [PLATFORM OR VERSION] — e.g., "browser and version, OS" or "app version"
  • [SLA] — Your actual response time commitment
  • [ANY OTHER LIMITATIONS] — What else can't the bot do? Be explicit to prevent it guessing

Code
Code Reviewer
Reviews diffs and code snippets for bugs, security issues, and logic errors — ignores style and formatting.
System Prompt
Customize these placeholders
  • [DOMAIN RULES] — Project-specific invariants: auth requirements, transaction rules, naming conventions that affect correctness
  • [PRIMARY LANGUAGE] — TypeScript, Python, Go, etc.
  • [FRAMEWORK] — Helps the model apply framework-specific idioms and security guidance

Data
JSON Data Extractor
Pulls structured fields from unstructured text and returns valid JSON — no prose, no hallucinated values.
System Prompt
Customize these placeholders
  • [FIELD_NAME]: [TYPE] — Your actual schema. Example: "invoice_number": "string", "total_amount": "number", "line_items": "array"
  • Add a one-line example below the schema if extraction is ambiguous — e.g., what counts as the "amount" when multiple numbers appear

Document Summarizer
Condenses long documents into a TL;DR, key points, and action items — no added interpretation.
System Prompt
Customize these placeholders
  • [DOMAIN RULES] — Add domain-specific flags: legal obligations, financial figures, deadlines, named entities that always need attention
  • Remove the "Notable gaps" section if your documents are consistently complete

Data
Text Classifier
Assigns incoming text to exactly one predefined category — useful for routing, moderation, and intent detection.
System Prompt
Customize these placeholders
  • [CATEGORY_N] and descriptions — Be specific about boundaries. "billing" vs "pricing" need clear definitions
  • Few-shot examples — Add 3–5 real examples. This is the highest-leverage customization for classifiers
  • Keep category names to one word — multi-word names confuse the output parser

Code
SQL Query Generator
Translates natural language questions into SQL queries for a specific schema — asks for clarification before guessing.
System Prompt
Customize these placeholders
  • [DIALECT] — SQL dialect affects date functions, string ops, and JSON support
  • [PASTE YOUR SCHEMA HERE] — Include table names, column names, types, and foreign key relationships. The more schema context, the fewer clarifying questions

System Prompt
Customize these placeholders
  • [PRIMARY LANGUAGE] — Include the major version if it matters (Python 3.12, Node 22, Go 1.22)
  • [Style preferences] — This is the highest-leverage line. Specific preferences drastically reduce back-and-forth on style

Writing
Writing Editor
Improves prose for clarity and concision without changing the author's voice, meaning, or intentional style.
System Prompt
Customize these placeholders
  • [DOMAIN / AUDIENCE] — e.g., "legal contracts", "developer documentation", "consumer marketing" — defines what counts as jargon
  • [TERMS TO NEVER CHANGE] — Brand names, product names, required legal phrasing. The model will try to simplify these without this guard

Data
JSON API Responder
Always returns valid JSON — never free text — for programmatic integrations. Includes success/error envelope.
System Prompt
Customize these placeholders
  • [TASK DESCRIPTION] — Be specific. "Analyze sentiment" is worse than "Return sentiment as 'positive', 'negative', or 'neutral' plus a score from -1.0 to 1.0"
  • [YOUR RESPONSE FIELDS HERE] — Replace with your actual data fields and types so the model learns the expected shape
  • Add a one-line example response to anchor the format

Support
Onboarding Guide
Walks new users through a setup process one step at a time — confirms each step before proceeding, handles errors gracefully.
System Prompt
Customize these placeholders
  • [PRODUCT / FEATURE] — Specific feature name, not just the product (e.g., "Zapier integration" not just "the app")
  • Setup steps — Each step needs: the action AND the success condition ("click Connect" + "you'll see a green checkmark")
  • Known issues — The most common stuck point at each step. This is where onboarding bots fail without it

Data
Content Moderator
Classifies user-generated content as approve / flag / remove — returns JSON with confidence score for borderline cases.
System Prompt
Customize these placeholders
  • [CUSTOM RULE N] — Platform-specific rules. Be precise: "promotional mentions of competitor brands" not just "competitors"
  • Tune the confidence threshold (0.85 here) based on your false-positive tolerance — lower = more flags
  • Add a "Context" field to the input schema if you want to pass metadata (author history, post location) that affects the decision
